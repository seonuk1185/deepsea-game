# 심해 포격전(가칭) — 게임 코드

5단계 2번-2: **조이스틱 이동 + 궤도 판 점 끌기 + 발사 꾹 누르기(거리 정하기) + 어뢰 발사**까지 만든 상태입니다. (2026-10-27)
궤도 판·조류 표시를 원작 기준으로 고쳤습니다 (점을 정확히 지나는 곡선, 4면 노란 한계 상자, 조류 4방향 + 1~5단계).
5차 수정: 노란 한계 상자를 잠수함 쪽 끝(곡선·발사 게이지 시작점)에 붙임 + 점 미세조정 ▲▼ 버튼 추가.
6차 수정: 궤도 판 = 모눈종이(한 칸 = 거리 1, 잠수함 쪽 끝 = 0, 판 끝 = 40), 아래 숫자 3칸마다 3·6·9…39. config.js 가로 값은 전부 「거리 칸」 (1칸 = 맵 48).
7차: **어뢰 발사** — 발사 버튼을 떼면 어뢰가 궤도 곡선대로 날아가 정한 거리(DELAY)에서 터짐 + 조류에 밀림 + 스친 데미지·폭발 데미지·격침 표시.
8차: 폰에서 궤도 판 크게(계기판 높이 140, 내 잠수함 창 숨김) + 발사 게이지는 끝까지 차면 멈추고 자동 발사 + 어뢰가 끝나거나 턴 넘기기를 누르면 거리 게이지 비움.
9차: 계기판 **가운데(궤도 판)만 위로 솟게**(양옆 112, 가운데 +40) + 내 잠수함 창 다시 보이기 + 발사·턴 넘기기 버튼 작게 + 이동·에너지 게이지 **세로 통**으로 + 아이템 4칸을 **바다 왼쪽 위 가로 한 줄**로 옮김 + 발사 게이지 조금 느리게(1.6초).
10차: 폰에서 계기판이 화면 1/3쯤 차지해서 **낮춤** — 거리 눈금 숫자를 **판 안 맨 아래**로 넣고 판 둘레 여백·틈을 줄여서, 계기판 전체 높이 152 → 122 (844×390 기준)인데 판 화면은 362×110 → 369×108로 거의 그대로. 양옆 112 → 88, 솟은 높이 40 → 34. 아이템 4칸은 **시간·DELAY 칸 바로 위**로 옮기고 조금 작게(30px), 조이스틱은 그 위로 살짝 올림.

## 여는 법
- `index.html`을 더블클릭하면 크롬에서 바로 열립니다. 인터넷이 연결돼 있어야 글꼴이 예쁘게 나옵니다.
- 폰에서 보려면 나중에 인터넷 주소(웹 서버)에 올려야 합니다. 어느 주소 밑에 올려도 작동하게 만들어 뒀습니다.
- 컴퓨터에서 폰 크기로 보기: 크롬 F12 → 폰 모양 버튼 → 가로 화면 선택.

```
├─ js/torpedo.js         어뢰 날아가기(곡선·조류) → 정한 거리에서 폭발 → 스침·폭발 데미지 → 카메라 따라가기

```

## 된 것
- 가로 전체 화면, 노치 비켜가기, 확대/스크롤 막기, 세로로 들면 「폰을 옆으로 돌려 주세요」
- 맵이 화면보다 넓음 → 바다를 손가락으로 밀면 화면이 움직임 (계기판·조이스틱·버튼 위에서는 안 움직임)
- 잠수함 2대(임시 그림) + 이름·노란 체력바, 내 잠수함 머리 위 통통 튀는 화살표, 보급상자 자리
- 계기판: 시간·DELAY / 궤도 판(노란 한계 상자·파란 곡선·× 점 3개·주황 거리 게이지·거리 눈금) / 조류+다시 / 이동·에너지 세로 게이지 / 내 잠수함 창 / 발사·턴 넘기기
- **계기판 가운데만 솟음**: 양옆 높이 88(태블릿 124), 궤도 판 칸만 그보다 34(태블릿 28) 더 위로 튀어나온 금속 판 → 판 세로가 넓어짐 (css `--dash-h`, `--dash-rise`). 계기판 전체 높이 = 폰 122, 태블릿 152. 판 둘레 여백은 최소로(위 2px·옆 3px, ▲▼ 띠와 틈 3px) → 폰 844×390에서 판 화면 약 369×108. 바다는 양옆 계기판 위까지 보이고, 조이스틱·맵 이름은 솟은 칸보다 위에 있어서 안 가려짐
- 양옆 부품도 낮아진 높이에 맞춰 조금씩 작게 (시간 숫자 32px, 조류 칸 36px, ↺ 버튼 높이 34, 내 잠수함 그림 조금 작게) — 잘리는 것 없음
- 판 모눈은 판이 커져도 늘 정사각형 (한 칸 크기 = 판 가로 ÷ 40)
- 발사 버튼(높이 36, 태블릿 50)·턴 넘기기(높이 32, 태블릿 40)는 작게, 칸 가운데에. 폰에서는 「▶▶」 표시 뺌
- **아이템 4칸**: 계기판 왼쪽 끝 **시간·DELAY 칸 바로 위**에 가로 한 줄 (동그라미 30px, 태블릿 40px, css `--item-size`). 줄이 시간 칸보다 넓어서 솟은 궤도 판과 안 겹치게 솟은 칸 높이 바로 위에 놓임. 누르면 모양만 바뀜(아이템 쓰기는 아직)
- 좁은 폰(가로 720 미만)은 시간·내 잠수함 창·버튼 칸을 조금씩 좁혀서 궤도 판 자리를 확보 (내 잠수함 창은 이제 모든 폰에서 보임)
- 처음 열 때 계기판 테두리 노랗게 번쩍(턴 시작 연출 미리보기)
- 버튼은 누르는 순간 모양만 바뀜 (턴 넘기기만 아래 임시 기능 있음)
- **조이스틱 이동**: 왼쪽 아래 동그라미(아이템 줄 바로 위)를 끌면 그 방향·세기대로 위아래·좌우·대각선 자유 이동. 손을 떼면 손잡이가 가운데로 돌아감
- **이동 게이지** (세로 통, 아래에서 위로 참): 간 거리만큼 줄고, 다 닳으면 멈춤 (가득 = 480만큼, config.js에서 바꿈). 20% 이하면 노란색
- 좌우로 밀면 잠수함이 그쪽을 보고, 궤도 판도 같이 좌우 반전
- 맵 밖으로 못 나감 (위쪽은 이름표 자리만큼 띄움)
- 잠수함이 움직이면 화면이 부드럽게 따라감. 바다를 손으로 밀면 따라가기 멈춤 → 다음에 조이스틱 잡으면 다시 따라감
- 조이스틱 누른 채 다른 손가락으로 바다 밀기 가능
- (임시) 「턴 넘기기」를 누르면 이동 게이지가 다시 가득 + 주황 거리 게이지 비움 + DELAY 칸 「--」로 — 턴 진행을 만들면 바뀜
- **거리 눈금은 판 안 맨 아래**: 1칸마다 작은 금(판 맨 아래), 3칸마다 숫자 3·6·9…39 (작은 글씨 + 어두운 띠·검은 테두리로 모눈 위에서도 읽힘). 손가락은 눈금 띠를 지나 그대로 판에 닿음. 잠수함이 왼쪽을 보면 눈금도 거울처럼 39…3
- **궤도 판 점 끌기**: × 점 3개를 손가락으로 잡고 위아래로만 끌면 곡선이 바로 바뀜. 가로 자리는 캐릭터마다 고정(`character.padPoints`). 점 주변 넉넉히(지름 52px) 눌러도 잡힘
- **곡선**: 잠수함 쪽 끝 세로 가운데(= 내 잠수함 높이)에서 출발 → 점1·2·3을 정확히 지나 → 판 끝까지 이어지는 파란 선. 노란 상자 밖으로 나가도 됨(판 밖은 잘림)
- **노란 한계 상자 (4면)**: `config.js character.limit` — 위·아래 = 발사 각도(점이 이 안에서만), 잠수함 쪽 변 = 판 끝에 딱 붙음(`left: 0`, 곡선·발사 게이지가 시작하는 곳. 나중에 최소 거리가 있는 캐릭터만 값을 올림), 바라보는 쪽 변 = 최대 거리(발사 게이지가 여기서 멈춤). 바깥은 어둡게. 돌고래호(중간형) = 최대 거리 27, 핀 가로 5·14·27
- **점 고르기 + ▲▼ 미세조정**: 점을 톡 누르면(끌기 시작해도) 그 점이 골라져 노랗게 빛남 (처음엔 가운데 점2). 판 오른쪽 옆 ▲/▼ 를 한 번 누르면 골라 둔 점이 딱 한 칸(`config.js pad.nudgeStep` = 판 높이의 1%) 위·아래로. 꾹 누르면 0.35초 뒤부터 0.08초마다 계속. 노란 상자 위·아래 변에서 멈춤. ▲▼ 사이 작은 글씨 = 지금 고른 점(점1·2·3). ▲▼ 띠는 잠수함이 돌아봐도 늘 판 오른쪽(엄지 자리)
- **조류**: 화살표 4방향(위·아래·왼쪽·오른쪽, 화면 기준이라 잠수함이 돌아봐도 그대로) + 세기 1~5 큰 숫자 + 5칸 막대. 0 = 조류 없음(화살표 숨김). `config.js current`
- **↺ 다시**: 점이 캐릭터 기본 모양으로 돌아감 (기본 모양은 config.js `character.padPoints`)
- **발사 꾹 누르기**: 누르고 있는 동안 주황 게이지가 잠수함 쪽 끝 → 노란 상자 오른쪽 변(최대 거리)까지 차오르고 거기서 멈춤. 중간에 손을 떼면 멈춘 흰 표시 자리 = 터지는 거리. 끝까지 차면 손을 안 떼도 최대 거리로 자동 발사(그 뒤 손을 떼도 또 쏘지 않음). 왼쪽 DELAY 칸에 거리 칸 숫자(0~최대 거리, 반올림)가 뜸 (처음엔 「--」). 빠르기는 config.js `fire.sweepTime`(한 번 차는 데 1.6초)
- **어뢰 발사** (설정값은 전부 config.js `torpedo`):
  - 발사 버튼을 떼면(또는 게이지가 끝까지 차면) 내 잠수함 앞코에서 바라보는 쪽으로 출발. 주황·빨강 어뢰 + 흰 거품 꼬리, 날아가는 방향으로 기울어짐
  - 길 = 궤도 판 곡선 그대로: 가로 1칸 = 맵 48, 판 세로 가운데 = 내 잠수함 높이, 판 맨 위·맨 아래 = 위·아래로 맵 220(`verticalRange`). 발사 순간의 곡선을 씀(날아가는 중 판을 만져도 이번 어뢰는 그대로)
  - 빠르기 = 맵 450/초(`speed`), 거리 27 ≈ 3초
  - 조류: 날아간 시간만큼 점점 더 밀림. 1단계마다 맵 10/초(`currentPush`) → 조류 5단계로 거리 20 쏘면 약 맵 107(2칸 남짓) 밀림
  - **정한 거리(DELAY 숫자)에 닿았을 때만 폭발** (번쩍 + 폭발 범위만큼 퍼지는 고리 + 거품 0.6초, 화면 살짝 흔들림)
  - 가는 길에 잠수함 몸을 뚫고 지나가면 안 터지고 그 잠수함 에너지 -5(`grazeDamage`), 한 발에 잠수함마다 한 번. 쏜 잠수함은 빼고, 몸 안에서 바로 터지면 스침은 없고 폭발 데미지만
  - 폭발 범위(반지름 맵 120, `blastRadius`) 안 잠수함은 **내 잠수함도** 깎임: 한가운데 -35(`maxDamage`), 범위 끝으로 갈수록 일직선으로 줄어듦. 머리 위 체력바 + 계기판 에너지(세로 통 높이 + 위 숫자) + 「-28」 같은 빨간 숫자
  - 체력 0 → 잠수함 회색 + 머리 위 「격침」 (아직 게임 끝내기는 없음, 새로고침하면 처음부터)
  - 맵 밖으로 나가면 작은 연기만 남기고 사라짐 (데미지 없음)
  - 카메라가 어뢰를 따라가고, 터진 곳에서 0.8초 머문 뒤 내 잠수함으로 돌아감
  - 날아가는 동안 발사·이동 잠김(발사 버튼·조이스틱이 흐려짐), 끝나면 풀리고 주황 거리 게이지도 비워짐 (DELAY 숫자는 턴 넘기기 때 지움)
- 잠수함이 왼쪽을 보면 점·곡선·한계 상자·게이지도 전부 거울처럼 반대로 작동 — 한계 상자는 이때도 잠수함 쪽(오른쪽) 끝에 붙음 (조류 화살표·▲▼ 버튼만 화면 기준 그대로)
- 조이스틱 누른 채 다른 손가락으로 점 끌기·발사 누르기 가능. 판 위에서 끌어도 바다 화면은 안 움직임
