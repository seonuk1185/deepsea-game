# 심해 포격전(가칭) — 게임 코드

5단계 2번-2: **조이스틱 이동 + 궤도 판 점 끌기 + 발사 꾹 누르기(거리 정하기) + 어뢰 발사**까지 만든 상태입니다. (2026-10-27)
궤도 판·조류 표시를 원작 기준으로 고쳤습니다 (점을 정확히 지나는 곡선, 4면 노란 한계 상자, 조류 4방향 + 1~5단계).
5차 수정: 노란 한계 상자를 잠수함 쪽 끝(곡선·발사 게이지 시작점)에 붙임 + 점 미세조정 ▲▼ 버튼 추가.
6차 수정: 궤도 판 = 모눈종이(한 칸 = 거리 1, 잠수함 쪽 끝 = 0, 판 끝 = 40), 아래 숫자 3칸마다 3·6·9…39. config.js 가로 값은 전부 「거리 칸」 (1칸 = 맵 48).
7차: **어뢰 발사** — 발사 버튼을 떼면 어뢰가 궤도 곡선대로 날아가 정한 거리(DELAY)에서 터짐 + 조류에 밀림 + 스친 데미지·폭발 데미지·격침 표시.
8차: 폰에서 궤도 판 크게(계기판 높이 140, 내 잠수함 창 숨김) + 발사 게이지는 끝까지 차면 멈추고 자동 발사 + 어뢰가 끝나거나 턴 넘기기를 누르면 거리 게이지 비움.
9차: 계기판 **가운데(궤도 판)만 위로 솟게**(양옆 112, 가운데 +40) + 내 잠수함 창 다시 보이기 + 발사·턴 넘기기 버튼 작게 + 이동·에너지 게이지 **세로 통**으로 + 아이템 4칸을 **바다 왼쪽 위 가로 한 줄**로 옮김 + 발사 게이지 조금 느리게(1.6초).
10차: 폰에서 계기판이 화면 1/3쯤 차지해서 **낮춤** — 거리 눈금 숫자를 **판 안 맨 아래**로 넣고 판 둘레 여백·틈을 줄여서, 계기판 전체 높이 152 → 122 (844×390 기준)인데 판 화면은 362×110 → 369×108로 거의 그대로. 양옆 112 → 88, 솟은 높이 40 → 34. 아이템 4칸은 **시간·DELAY 칸 바로 위**로 옮기고 조금 작게(30px), 조이스틱은 그 위로 살짝 올림.
11차: **온라인 준비 뼈대** (화면·조작은 그대로, 속만 바꿈. 3단계 계획서 ⑨-①) — 나중에 서버·키보드·컴퓨터 상대를 붙이기 쉽게
  - **심판 / 화면 분리**: 규칙·데미지 계산은 새 파일 `js/rules.js`(심판)만 함. 진짜 상태(잠수함 자리·바라보는 쪽·체력·팀·격침·이동 게이지, 조류, 차례)도 심판이 들고 있음. 나머지 파일은 「보여 주기」만
  - **어뢰는 쏘는 순간 한 번에 계산**: 예전엔 화면이 그려질 때마다 조금씩 날리며 데미지를 줬는데, 이제 심판이 일정한 걸음(맵 6씩)으로 끝까지 미리 계산 → 날아간 길·「몇 초에 누가 얼마나」 데미지 목록·폭발 자리를 돌려줌. `torpedo.js`는 그걸 시간에 맞춰 다시 보여 주기만 함 (체력바·숫자는 맞는 순간에 바뀜)
  - **모든 행동 = 주문서(쪽지)**: 조이스틱·발사·턴 넘기기는 쪽지만 만들어 `Game.submit(쪽지)` 한 곳으로 냄 → 심판이 처리 → 화면이 결과대로 그림. 나중에 키보드·인터넷 상대·컴퓨터 상대도 같은 쪽지만 내면 됨
  - **같은 주사위**: 번호(`config.js seed`)를 넣으면 늘 같은 순서로 나오는 주사위를 심판 안에 둠. 운에 맡기는 건 전부 여기서만 굴림 → 같은 번호 + 같은 쪽지 = 어느 컴퓨터든 같은 결과 (14차부터 조류를 차례마다 여기서 굴림. 2026-10-28부터 첫 차례도)
  - **여러 명·팀 차례 자료**: 잠수함마다 팀 이름(`team`), 차례 순서(`turnOrder`), 다음 차례 찾기 도우미만 만들어 둠 (차례 돌리기·20초 시계·컴퓨터 상대는 다음 ②·③ 단계)
  - 확인: 예전 코드와 새 코드로 같은 조건 8발을 쏴서 데미지·체력·폭발 자리가 같음을 확인 (맵 밖으로 나간 1발만 연기 자리가 맵 1칸도 안 되게 다름 — 예전엔 화면 빠르기에 따라 걸음이 달랐기 때문)
12차: **PC 지원** (같은 주소 하나로 폰·PC 둘 다. 폰 화면은 그대로) — 아래 「PC에서 하기」
  - **키보드 조작** (새 파일 `js/keys.js`, 키 목록은 `config.js keys` 한 곳): WASD 이동 · 화살표 화면 둘러보기 · 스페이스 꾹 발사 · 1~4 아이템 칸 · Ins/Del·Home/End·PgUp/PgDn 점1·2·3 ▲▼ · F1 ↺ · Tab 턴 넘기기 · ? 키 안내. 키는 화면 버튼과 **같은 코드**를 불러서 같은 쪽지가 나감 (이동 걸음 계산·발사 꾹 누르기·▲▼ 꾹 누르기 코드를 하나로 묶음)
  - **PC 화면 다듬기**: 가로 1180 이상 PC 창은 계기판을 더 높여서 궤도 판을 세로로 크게, 발사·턴 넘기기 버튼도 크게. 판이 옆으로만 길어지지 않게 「가로 ≤ 세로 × 4.6」
  - **마우스 PC**(손가락 화면 없음)는 화면 조이스틱·판 옆 ▲▼ 띠를 숨김 (키보드가 대신함) → 판이 그만큼 넓어짐. 터치 노트북·태블릿·폰은 그대로 보임. 오른쪽 아래 작은 「?」 = 키 안내
  - **턴 시작 번쩍 고침**: 노란 테두리가 옛날 네모 모양으로 번쩍이던 것 → 가운데 솟은 칸까지 계기판 진짜 모양대로 번쩍 (선 + 안쪽 빛)
  - 아이템 칸을 누르면(또는 1~4) 그 칸이 골라짐(노란 테두리). 아이템 쓰기는 아직
  - **12차 보강** (형님 PC 시험 후): 점 키 꾹 누르기를 더 빠르게(0.18초 뒤부터 1초에 약 28칸, 버튼은 그대로) + **다른 점 키는 같이 눌러 동시에** 움직임 + 화살표로 둘러본 뒤 WASD 로 움직여도 카메라가 잠수함으로 안 끌려옴
13차: **키 설정 화면** (PC) + **「내 잠수함으로 화면 돌아가기」 동작** — 아래 「키 설정 (13차)」. 폰 화면은 그대로
14차: **턴 + 20초 시계 + 미니맵** (3단계 계획서 ⑨-②) — 아래 「턴과 20초 시계 (14차)」「미니맵 (14차)」
  - 나 ↔ 상대 번갈아 차례. 20초가 다 되면 저절로 넘어감 / 턴 넘기기 (쏘면 어뢰가 끝난 뒤 넘어감 → 2026-10-28 바뀜: 아래 「14차 보강」). 상대는 아직 2초 뒤 턴만 넘김 (컴퓨터 상대는 ③)
  - 상대 차례엔 내 이동·발사·턴 넘기기 잠김 + 오른쪽 아래 「상대 차례」 표시. 격침되면 못 움직임. 한 팀만 남으면 승리/패배 화면 + 다시 하기
  - 오른쪽 위 Ⅱ 단추 밑에 미니맵 (상대 위치 늘 보임, 누르면 그 자리로 화면 이동)
14차 보강 (2026-10-28, 형님 결정으로 규칙 바꿈 — 그전 값은 클로드가 임시로 정한 것): 아래 「턴과 20초 시계」에 반영
  - **쏜 뒤에도 이동 가능** (게이지·시간이 남았으면). 한 차례 한 발은 그대로 → 쏜 뒤 발사 버튼만 흐리게. 차례는 시간 끝 / 턴 넘기기로만 넘어감
  - **쏴도 시계는 계속 감** (어뢰가 날아가는 동안에도). 날아가는 중에 0 이 되면 재생을 끝까지 보여 준 뒤 넘어감
  - **0 이 되기 전에 발사를 누르기 시작했으면** 시간 끝이 끊지 않음 → 떼거나 끝까지 차면 쏨 (0 이 된 뒤 새로 누르기는 안 됨)
  - **조류는 첫 차례부터 무작위** (같은 주사위라 같은 번호면 같은 조류)

## 여는 법
- `index.html`을 더블클릭하면 크롬에서 바로 열립니다. 인터넷이 연결돼 있어야 글꼴이 예쁘게 나옵니다.
- 폰에서 보려면 나중에 인터넷 주소(웹 서버)에 올려야 합니다. 어느 주소 밑에 올려도 작동하게 만들어 뒀습니다.
- 컴퓨터에서 폰 크기로 보기: 크롬 F12 → 폰 모양 버튼 → 가로 화면 선택.

## 폴더 구조
```
game/
├─ index.html            화면 뼈대
├─ manifest.webmanifest  나중에 앱(바탕화면 아이콘)으로 만들 때 쓰는 이름표
├─ css/style.css         색·크기·모양 (맨 위에 색상표 모음)
├─ js/config.js          ★ 숫자 설정 모음 (맵 크기, 잠수함 위치·팀, 차례 순서, 내 잠수함(mySubId), 턴 시간·상대 넘기기 시간(turn), 주사위 번호, 노란 한계 상자, 점 자리, 조류, 이동 빠르기·게이지, PC 키 목록…)
├─ js/rules.js           ★ 심판 (게임 규칙). 진짜 상태 + 주문서 처리 + 이동 계산 + 어뢰 한 발 전체 계산 + 같은 주사위 + 차례 진행(마감 시각·한 차례 한 발·게이지 채우기·조류 굴리기·판 끝). 화면은 모름 (나중에 서버로 옮길 부분)
├─ js/main.js            화면 그리기 + 카메라 + 바다 끌어서 둘러보기 + 주문서 창구(Game.submit → 심판 → 화면 바꾸기)
├─ js/move.js            조이스틱·WASD → 이동 쪽지 + 화살표 화면 둘러보기 + 카메라 따라가기 + 턴 넘기기 → 턴 넘기기 쪽지
├─ js/pad.js             궤도 판 점 3개 끌기 + 점 고르기 + ▲▼ 미세조정 + ↺(다시) 버튼 (조준은 발사 쪽지에 담김)
├─ js/fire.js            발사 꾹 누르기 → 거리 게이지 차오름 → 떼면(또는 끝까지 차면) 거리(DELAY) 결정 → 발사 쪽지
├─ js/torpedo.js         심판이 계산한 어뢰 결과를 재생: 날아가기 → 폭발/연기 → 데미지 숫자·격침 → 카메라 따라가기
├─ js/turn.js            (14차) 차례 진행 화면: 20초 시계 보여 주기·시간 끝 쪽지(어뢰 재생 중·발사 누르는 중엔 미룸), 어뢰 끝나면 판 끝 화면, 차례 바뀔 때 카메라·번쩍·「상대 차례」 표시, 컴퓨터 상대 자리(Game.bots, 지금은 2초 뒤 넘기기), 승리/패배 화면
├─ js/minimap.js         (14차) 오른쪽 위 미니맵: 잠수함·보급상자·어뢰·화면 네모, 누르면 그 자리로
├─ js/keys.js            PC 키보드: 키를 누르면 화면 버튼과 같은 코드를 부름 (기본 키 = config.js keys, 바꾼 키 = 브라우저 저장) + 오른쪽 아래 키 안내 + 키 설정 화면(13차)
├─ assets/bg-ruins.jpg   바다 배경 (「심해 유적」)
├─ assets/icon.svg       앱 아이콘(임시)
└─ shots/                확인용 화면 사진 (큰 폰·작은 폰·태블릿·세로, step2-* = 조이스틱 이동, step3-* = 점 끌기·발사 게이지 확인, step4-* = 원작식 궤도 판·조류 확인, step5-* = 한계 상자 붙이기·▲▼ 미세조정 확인, step8-* = 거리 눈금(한 칸=1) 확인, step9-* = 어뢰 비행·폭발·데미지 숫자·격침 확인, step10-* = 가운데 솟은 계기판·세로 게이지·위로 옮긴 아이템 칸, step11-* = 낮아진 계기판·판 안 거리 눈금·시간 칸 위 아이템 줄·왼쪽 볼 때 거울 눈금)
```

## 된 것
- 가로 전체 화면, 노치 비켜가기, 확대/스크롤 막기, 세로로 들면 「폰을 옆으로 돌려 주세요」
- 맵이 화면보다 넓음 → 바다를 손가락으로 밀면 화면이 움직임 (계기판·조이스틱·버튼 위에서는 안 움직임)
- 잠수함 2대(임시 그림) + 이름·노란 체력바, 내 잠수함 머리 위 통통 튀는 화살표, 보급상자 자리
- 계기판: 시간·DELAY / 궤도 판(노란 한계 상자·파란 곡선·× 점 3개·주황 거리 게이지·거리 눈금) / 조류+다시 / 이동·에너지 세로 게이지 / 내 잠수함 창 / 발사·턴 넘기기
- **계기판 가운데만 솟음**: 양옆 높이 88(태블릿 124), 궤도 판 칸만 그보다 34(태블릿 28) 더 위로 튀어나온 금속 판 → 판 세로가 넓어짐 (css `--dash-h`, `--dash-rise`). 계기판 전체 높이 = 폰 122, 태블릿 152 (PC 창은 더 높음 — 아래 「PC에서 하기」). 판 둘레 여백은 최소로(위 2px·옆 3px, ▲▼ 띠와 틈 3px) → 폰 844×390에서 판 화면 약 369×108. 바다는 양옆 계기판 위까지 보이고, 조이스틱·맵 이름은 솟은 칸보다 위에 있어서 안 가려짐
- 양옆 부품도 낮아진 높이에 맞춰 조금씩 작게 (시간 숫자 32px, 조류 칸 36px, ↺ 버튼 높이 34, 내 잠수함 그림 조금 작게) — 잘리는 것 없음
- 판 모눈은 판이 커져도 늘 정사각형 (한 칸 크기 = 판 가로 ÷ 40)
- 발사 버튼(높이 36, 태블릿 50)·턴 넘기기(높이 32, 태블릿 40)는 작게, 칸 가운데에. 폰에서는 「▶▶」 표시 뺌
- **아이템 4칸**: 계기판 왼쪽 끝 **시간·DELAY 칸 바로 위**에 가로 한 줄 (동그라미 30px, 태블릿 40px, css `--item-size`). 줄이 시간 칸보다 넓어서 솟은 궤도 판과 안 겹치게 솟은 칸 높이 바로 위에 놓임. 누르면(PC는 1~4 키) 그 칸이 골라짐 = 노란 테두리 (아이템 쓰기는 아직, 빈 칸은 안 골라짐)
- 좁은 폰(가로 720 미만)은 시간·내 잠수함 창·버튼 칸을 조금씩 좁혀서 궤도 판 자리를 확보 (내 잠수함 창은 이제 모든 폰에서 보임)

## PC에서 하기 (12차)
- 폰과 **같은 주소**. 화면 크기·마우스 여부를 보고 알아서 모양이 바뀜 (폰 화면 = 높이 600 미만은 그대로)
- 키 (기본값. 게임 안 「키 설정」 화면에서 바꿀 수 있음 — 아래 「키 설정 (13차)」. 기본값 자체는 `js/config.js` 의 `keys`. 한글 입력 상태여도 됨):

  | 키 | 하는 일 |
  |---|---|
  | W A S D | 잠수함 이동 (두 개 같이 = 대각선). 조이스틱과 같은 계산·같은 이동 쪽지 |
  | ← ↑ ↓ → | 화면(바다) 둘러보기 — 손가락으로 바다를 미는 것과 같음 (잠수함 따라가기 멈춤. 그 뒤 WASD 로 움직여도 화면은 그대로) |
  | Space | 꾹 누르면 거리 게이지가 참 → 떼면 발사, 끝까지 차면 자동 발사 (발사 버튼과 똑같음) |
  | 1 2 3 4 | 아이템 칸 고르기 |
  | Insert / Delete | 점1(잠수함에 가장 가까운 점) ▲ / ▼ |
  | Home / End | 점2 ▲ / ▼ |
  | PageUp / PageDown | 점3 ▲ / ▼ |
  | F1 | ↺ 점 처음 모양 |
  | Tab | 턴 넘기기 (내 차례일 때만, 14차) |
  | ? | 키 안내 열기/닫기 |
  | (없음) | 내 잠수함으로 화면 돌아가기 — 기본 키 없음, 키 설정에서 정함 |

  - 점 키: 누르면 그 점이 골라지고(노란 빛) 한 칸, 꾹 누르면 **0.18초 뒤부터 0.035초마다**(1초에 약 28칸) 계속 — 화면 ▲▼ 버튼(0.35초 뒤 0.08초마다, 1초에 12.5칸)보다 빠름. 한 번 누를 때 한 칸은 버튼과 같아서 톡톡 눌러 미세조정 가능. 빠르기는 `config.js pad.keyRepeatDelay`·`keyRepeatEvery`. ▲ = 늘 판 위쪽 (잠수함이 왼쪽을 봐도)
  - **다른 점은 동시에**: 예) Insert(점1 ▲) + PageDown(점3 ▼) 을 같이 꾹 → 두 점이 같이 움직임. 하나를 떼도 다른 점은 계속. 노란 빛은 마지막에 누른 점 키를 따라감
  - 같은 점의 ▲·▼ 를 같이 누르면 **나중에 누른 쪽**만 움직임 (그 키를 떼면 아직 누르고 있는 반대쪽으로 이어감)
  - **카메라**: 한 번도 안 둘러봤으면 WASD 로 움직일 때 화면이 잠수함을 따라감 (예전과 같음). 화살표(또는 마우스로 바다 끌기)로 둘러본 뒤에는 WASD 로 움직여도 **화면이 그 자리에 그대로**. 화면이 다시 잠수함으로 돌아오는 때 = **어뢰를 쏘고 나서** (어뢰를 따라갔다가 터진 곳에서 0.8초 뒤 내 잠수함으로 돌아오고, 그다음부터는 WASD 로 움직이면 다시 따라감). 터치 화면이면 조이스틱을 잡아도 돌아옴. 13차부터 **「내 잠수함으로 화면 돌아가기」** 동작도 있음 (기본 키 없음 → 키 설정에서 정하면 그 키로 바로 돌아가고 다시 WASD 를 따라감)
  - 이동 키와 둘러보기 키를 바꾸고 싶으면 게임 안 「키 설정」에서 바꾸면 됨 (기본값 자체를 바꾸려면 `config.js keys` 에서 `up·down·left·right` 줄과 `camUp·camDown·camLeft·camRight` 줄의 키 이름만 서로 바꾸면 됨)
  - 키를 꾹 누를 때 자동 반복 신호는 무시. 어뢰가 날아가는 동안은 버튼처럼 발사·이동이 잠김
  - 화살표·스페이스로 화면이 스크롤되지 않고, F1 도움말 창·Tab 칸 이동도 막음. Ctrl·Alt 를 같이 누르면 게임이 안 받음 (Ctrl+R 새로고침 등은 그대로)
  - 다른 창으로 넘어가면 누르던 키는 전부 놓은 걸로 (발사는 안 쏘고 원래대로)

## 키 설정 (13차, PC)
- **여는 법**: 오른쪽 아래 「?」(또는 ? 키) → 키 안내 맨 아래 **「키 설정」** 단추. (왼쪽 위 Ⅱ 일시정지 단추는 아직 아무 일도 안 해서 건드리지 않음)
- 동작마다 키 칸 2개(첫째·둘째). 칸을 누르면 「키를 누르세요」 → 다음에 누른 키가 그 칸에 들어감. **Esc = 취소**, 기다리는 칸을 한 번 더 누르면 그 칸을 **비움**(「없음」). 키 이름은 「스페이스」「Page Up」「Insert」「←」「숫자판 1」처럼 보임
- **겹치는 키 = 서로 바꾸기**: 이미 다른 동작에 쓰는 키를 고르면 노란 경고 줄이 뜨고, 그 동작에는 이 칸에 원래 있던 키가 들어감 (예: 발사 칸에 W → 「이동 위」 = 스페이스). 이 칸이 비어 있었으면 그쪽은 「없음」. 지우기 대신 바꾸기로 한 이유: 바꾸다가 발사 같은 중요한 동작이 실수로 키 없이 남지 않게
- 못 쓰는 키: Esc(취소용)·F5(새로고침)·F11(전체 화면)·F12(개발자 창), Ctrl·Alt·Windows 키와 같이 누른 키 → 경고만 뜨고 브라우저 기능은 그대로
- 바꾸면 **바로 적용** + 키 안내(?)도 바로 바뀜. **「기본값으로」** = 전부 config.js 기본 키로
- 저장: 브라우저(localStorage, 이름 `deepsea.keys.v1`)에 「기본값과 달라진 동작」만 저장 → 다시 열어도 그대로. 불러올 때 기본값 위에 덮어써서, 나중에 config.js 에 새 동작을 더하면 그 동작은 기본 키로 시작 (저장된 키와 겹치면 저장된 쪽이 이김). 저장이 안 되는 브라우저(사생활 보호 창 등)면 이번 창에서만 바뀌고 게임은 기본값으로 정상 작동
- 설정 화면이 열려 있는 동안은 **게임 키가 전부 쉼** (이동·발사·턴 넘기기 안 됨, 누르고 있던 키도 안 쏘고 놓음). 꾹 누를 때 자동 반복 신호는 무시
- 설정 목록: 이동 위·아래·왼쪽·오른쪽, 화면 둘러보기 위·아래·왼쪽·오른쪽, **내 잠수함으로 화면 돌아가기**(기본 없음), 발사, 아이템 1~4, 핀1·2·3 ▲/▼, 핀 처음으로(↺), 턴 넘기기, 키 목록, (예비) 핀1·2·3 고르기·고른 핀 ▲/▼ (기본 없음)
- **내 잠수함으로 화면 돌아가기** (`move.js Game.recenter`): 화살표·마우스로 둘러보던 화면이 내 잠수함으로 부드럽게 돌아가고, 그다음 WASD 로 움직이면 다시 따라감. 어뢰가 날아가는 중엔 안 함 (어뢰가 끝나면 어차피 돌아옴)
- 손가락 화면만 있는 폰·태블릿은 「?」가 원래 안 보여서 설정 화면도 없음 (폰 화면 그대로)
