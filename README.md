# 심해 포격전(가칭) — 게임 코드

5단계 2번-2: **조이스틱 이동 + 궤도 판 점 끌기 + 발사 꾹 누르기(거리 정하기)**까지 만든 상태입니다. (2026-10-27)
궤도 판·조류 표시를 원작 기준으로 고쳤습니다 (점을 정확히 지나는 곡선, 4면 노란 한계 상자, 조류 4방향 + 1~5단계).
5차 수정: 노란 한계 상자를 잠수함 쪽 끝(곡선·발사 게이지 시작점)에 붙임 + 점 미세조정 ▲▼ 버튼 추가.
6차 수정: 궤도 판 = 모눈종이(한 칸 = 거리 1, 잠수함 쪽 끝 = 0, 판 끝 = 40), 아래 숫자 3칸마다 3·6·9…39. config.js 가로 값은 전부 「거리 칸」 (1칸 = 맵 48).
어뢰는 아직 안 날아갑니다 (다음 단계).

## 여는 법
- `index.html`을 더블클릭하면 크롬에서 바로 열립니다. 인터넷이 연결돼 있어야 글꼴이 예쁘게 나옵니다.
- 폰에서 보려면 나중에 인터넷 주소(웹 서버)에 올려야 합니다. 어느 주소 밑에 올려도 작동하게 만들어 뒀습니다.
- 컴퓨터에서 폰 크기로 보기: 크롬 F12 → 폰 모양 버튼 → 가로 화면 선택.

## 폴더 구조
```
game/
├─ index.html            화면 뼈대
├─ manifest.webmanifest  나중에 앱(바탕화면 아이콘)으로 만들 때 쓰는 이름표
├─ css/style.css         색·크기·모양 (맨 위에 색상표 모음)
├─ js/config.js          ★ 숫자 설정 모음 (맵 크기, 잠수함 위치, 노란 한계 상자, 점 자리, 조류, 이동 빠르기·게이지…)
├─ js/main.js            화면 그리기 + 카메라 + 바다 끌어서 둘러보기
├─ js/move.js            조이스틱 → 잠수함 이동 + 이동 게이지 + 카메라 따라가기
├─ js/pad.js             궤도 판 점 3개 끌기 + 점 고르기 + ▲▼ 미세조정 + ↺(다시) 버튼
├─ js/fire.js            발사 꾹 누르기 → 거리 게이지 왕복 → 떼면 거리(DELAY) 결정
├─ assets/bg-ruins.jpg   바다 배경 (「심해 유적」)
├─ assets/icon.svg       앱 아이콘(임시)
└─ shots/                확인용 화면 사진 (큰 폰·작은 폰·태블릿·세로, step2-* = 조이스틱 이동, step3-* = 점 끌기·발사 게이지 확인, step4-* = 원작식 궤도 판·조류 확인, step5-* = 한계 상자 붙이기·▲▼ 미세조정 확인, step8-* = 거리 눈금(한 칸=1) 확인)
```

## 된 것
- 가로 전체 화면, 노치 비켜가기, 확대/스크롤 막기, 세로로 들면 「폰을 옆으로 돌려 주세요」
- 맵이 화면보다 넓음 → 바다를 손가락으로 밀면 화면이 움직임 (계기판·조이스틱·버튼 위에서는 안 움직임)
- 잠수함 2대(임시 그림) + 이름·노란 체력바, 내 잠수함 머리 위 통통 튀는 화살표, 보급상자 자리
- 계기판: 시간·DELAY / 아이템 4칸 / 궤도 판(노란 한계 상자·파란 곡선·× 점 3개·주황 거리 게이지·거리 눈금) / 조류+다시 / 이동·에너지 / 내 잠수함 창 / 발사·턴 넘기기
- 처음 열 때 계기판 테두리 노랗게 번쩍(턴 시작 연출 미리보기)
- 버튼은 누르는 순간 모양만 바뀜 (턴 넘기기만 아래 임시 기능 있음)
- **조이스틱 이동**: 왼쪽 아래 동그라미를 끌면 그 방향·세기대로 위아래·좌우·대각선 자유 이동. 손을 떼면 손잡이가 가운데로 돌아감
- **이동 게이지**: 간 거리만큼 줄고, 다 닳으면 멈춤 (가득 = 480만큼, config.js에서 바꿈). 20% 이하면 노란색
- 좌우로 밀면 잠수함이 그쪽을 보고, 궤도 판도 같이 좌우 반전
- 맵 밖으로 못 나감 (위쪽은 이름표 자리만큼 띄움)
- 잠수함이 움직이면 화면이 부드럽게 따라감. 바다를 손으로 밀면 따라가기 멈춤 → 다음에 조이스틱 잡으면 다시 따라감
- 조이스틱 누른 채 다른 손가락으로 바다 밀기 가능
- (임시) 「턴 넘기기」를 누르면 이동 게이지가 다시 가득 — 턴 진행을 만들면 바뀜
- **궤도 판 점 끌기**: × 점 3개를 손가락으로 잡고 위아래로만 끌면 곡선이 바로 바뀜. 가로 자리는 캐릭터마다 고정(`character.padPoints`). 점 주변 넉넉히(지름 52px) 눌러도 잡힘
- **곡선**: 잠수함 쪽 끝 세로 가운데(= 내 잠수함 높이)에서 출발 → 점1·2·3을 정확히 지나 → 판 끝까지 이어지는 파란 선. 노란 상자 밖으로 나가도 됨(판 밖은 잘림)
- **노란 한계 상자 (4면)**: `config.js character.limit` — 위·아래 = 발사 각도(점이 이 안에서만), 잠수함 쪽 변 = 판 끝에 딱 붙음(`left: 0`, 곡선·발사 게이지가 시작하는 곳. 나중에 최소 거리가 있는 캐릭터만 값을 올림), 바라보는 쪽 변 = 최대 거리(발사 게이지가 여기서 멈춤). 바깥은 어둡게. 돌고래호(중간형) = 최대 거리 27, 핀 가로 5·14·27
- **점 고르기 + ▲▼ 미세조정**: 점을 톡 누르면(끌기 시작해도) 그 점이 골라져 노랗게 빛남 (처음엔 가운데 점2). 판 오른쪽 옆 ▲/▼ 를 한 번 누르면 골라 둔 점이 딱 한 칸(`config.js pad.nudgeStep` = 판 높이의 1%) 위·아래로. 꾹 누르면 0.35초 뒤부터 0.08초마다 계속. 노란 상자 위·아래 변에서 멈춤. ▲▼ 사이 작은 글씨 = 지금 고른 점(점1·2·3). ▲▼ 띠는 잠수함이 돌아봐도 늘 판 오른쪽(엄지 자리)
- **조류**: 화살표 4방향(위·아래·왼쪽·오른쪽, 화면 기준이라 잠수함이 돌아봐도 그대로) + 세기 1~5 큰 숫자 + 5칸 막대. 0 = 조류 없음(화살표 숨김). `config.js current`
- **↺ 다시**: 점이 캐릭터 기본 모양으로 돌아감 (기본 모양은 config.js `character.padPoints`)
- **발사 꾹 누르기**: 누르고 있는 동안 주황 게이지가 잠수함 쪽 끝 → 노란 상자 오른쪽 변(최대 거리)까지 차고, 다시 내려오고… 왔다 갔다. 손을 떼면 멈추고 흰 표시 자리 = 터지는 거리. 왼쪽 DELAY 칸에 거리 칸 숫자(0~최대 거리, 반올림)가 뜸 (처음엔 「--」). 빠르기는 config.js `fire.sweepTime`(한 번 차는 데 1.2초)
- (임시) 거리를 정하면 바다 위에 「거리 27 결정」 글씨가 잠깐 뜸 — 어뢰 날아가기를 만들면 지움
- 잠수함이 왼쪽을 보면 점·곡선·한계 상자·게이지도 전부 거울처럼 반대로 작동 — 한계 상자는 이때도 잠수함 쪽(오른쪽) 끝에 붙음 (조류 화살표·▲▼ 버튼만 화면 기준 그대로)
- 조이스틱 누른 채 다른 손가락으로 점 끌기·발사 누르기 가능. 판 위에서 끌어도 바다 화면은 안 움직임
